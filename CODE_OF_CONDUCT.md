# Code of Conduct

HoverText exists to make Windows text easier to read for people who need larger, clearer, local context. Project discussions should support that goal.

## Expected behavior

- Be respectful and specific.
- Assume accessibility needs vary across users, displays, apps, and input methods.
- Keep feedback actionable when possible.
- Redact private screen content from reports.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Dismissing accessibility needs or assistive-technology feedback.
- Sharing another person's private information.
- Posting sensitive screenshots, credentials, or private documents.

Maintainers may edit, hide, or remove comments that make the project less useful or safe for contributors and users.
