# Support

HoverText is an early open-source Windows accessibility utility. Support is currently handled through GitHub issues.

## Before opening an issue

- Check that you are using the latest release.
- Note your Windows version and display scaling.
- Try the same screen with OCR installed and without OCR if the problem involves image-based text.

## Good issue details

- The app or screen where HoverText was used.
- The trigger key you used.
- What text you expected HoverText to show.
- What HoverText showed instead.
- Whether the text is selectable UI text, browser content, tooltip text, or image-based text.
- A redacted screenshot or short recording if it helps explain the issue.
