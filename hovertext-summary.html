HoverText 已实现

一个 Windows 悬浮文字放大工具：按住触发键读取鼠标下文字，显示大字号悬浮框，失败时依次进入 OCR 与像素放大兜底。

可构建，可测试，可启动 Release 构建 0 警告 0 错误，启动 smoke test 保持运行 3 秒。

测试结果

8项核心测试通过

覆盖探测链路、悬浮定位、默认设置与 JSON 设置持久化。

技术栈

C#、.NET 8、WPF、Windows UI Automation、Win32 API、Windows Forms 托盘。

交互方式

默认按住 Alt 显示悬浮放大内容；托盘可打开设置、切换 OCR、切换开机自启和退出。

功能链路

输入

触发键轮询

每 100 到 300ms 检查 Alt、Ctrl 或 Shift，并读取鼠标位置。

优先

UI Automation

尝试 TextPattern、ValuePattern、Name 与 HelpText。

兜底

Tesseract OCR

如果系统存在 tesseract.exe，截取鼠标附近区域识别文字。

最终

像素放大

文字不可读时显示鼠标周边截图，作为可视放大兜底。

输出

置顶悬浮窗

鼠标穿透、自动避开屏幕边缘，按设置展示字号和配色。

模块结构

HoverText.Core

纯逻辑核心：探测管线、设置模型、悬浮框定位算法。

HoverText.App

WPF 应用入口、控制器、托盘、设置窗口、平台能力适配。

Input

Win32 触发键检测与鼠标坐标读取。

Probing

UIA、Tesseract CLI OCR、屏幕截图放大。

Ui

OverlayWindow、SettingsWindow、TrayIconService。
